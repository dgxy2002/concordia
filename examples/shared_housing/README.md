# Shared Housing Simulation

This example turns `shared-housing-scenario.md` into a runnable Concordia
simulation. Resident decisions are generated by the language model. The game
master deterministically handles communication channels and filters messages
using the language proficiency explicitly stated in the scenario.

## Setup

From the repository root, create `.env`:

```text
OPENAI_API_KEY=your-key-here
```

Install the project and its OpenAI integration if needed:

```shell
python -m pip install -e ".[openai]"
```

Run the default late-kitchen episode:

```shell
python -m examples.shared_housing.run --episode late_kitchen --rounds 3
```

Run all six episodes with memories persisting between them:

```shell
python -m examples.shared_housing.run --episode all --rounds 2
```

Use a different supported model with `--model_name`. A no-cost wiring smoke
test is also available:

```shell
python -m examples.shared_housing.run --disable_language_model --rounds 1
```

Each run creates a timestamped folder under `outputs/shared_housing` containing
an HTML log, JSON log, readable transcript, and structured communication
metrics. The metrics include observed multilingual behavior and explicit targets
for non-English actions, code-switching, translation, and clarification. These
targets diagnose whether a run surfaced the intended behavior; they do not force
individual residents to act unnaturally.
